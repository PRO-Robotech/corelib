# Independent CI-NP-03/04 upload holder

Run from the corelib checkout with Node24, GOWORK=off, external TMPDIR,
CI_NP_SDK_ROOT pointing to the independently installed exact 6.2.1 lock,
and CI_NP_UPLOAD_EVIDENCE pointing to a fresh private capture directory:

```text
node --test ci/newman_publication/tests/upload.test.mjs
```

The driver first validates immutable real Newman captures, all four reader
outcomes, actual project plus file/stdin check, three genuine one-member ZIP
mutations, Node24, the pinned SDK Create/stream/Finalize path on the real
projected ZIP, OS AbortSignal child termination and the YAML parser. A socket guard counts and rejects any unrecorded connection. SDK code
is not replaced; HTTP/blob network boundaries record. No real runtime token
or external upload is used. Diagnostic canaries are synthetic.

Only after prerequisites pass does each declared case ask for publishSnapshot
or the fixed action. Missing product capability is classified separately from
unexecuted prerequisites and from an executed assertion failure. A baseline
capability refusal is not one distinct defect per case or completed behavior checks.
The exact declared and executed names, source SHA and raw captures are recorded.
Future candidate behavior is not claimed from a baseline missing-module run.

The module matrix covers lawful full bytes, caller-file mutation after check,
checker-copy mutation, three genuine ZIP member mutations, raw/missing input,
malformed checker schema/digest/counts, non-CLEAN results, reduced/invalid budgets,
controlled timeout/abort and transport mismatch/error. Fixed-main cases parse
actual action YAML, use the ordinary agreed INPUT_* names, run unchanged main
with pinned real SDK, and observe OS children plus recording network clients.
The fixed-main path-mutation twin changes its archive at CreateArtifact after
checker completion and compares the complete bytes received by SDK blob transport.
Main must suppress SDK diagnostics and keep all synthetic credentials out of
the checker environment. Child cleanup by this harness cannot count as main's
successful termination. The timeout assertion requires observed child closure
and no live children before main exit.

Routine inputs/exit agreement:
https://github.com/PRO-Robotech/kacho/issues/1810#issuecomment-5715635183
Inputs preserve hyphens after INPUT_ uppercasing. package.json/package-lock.json
live beside main.mjs in ci/newman_publication/action/ (author/root routine
coordination); this holder never writes those product files. Tests materialize
an unchanged private candidate snapshot and link the independently installed
lock dependencies there. Raw HTTP/blob protocol failures are SDK/network twins,
not a replacement publisher. Consumer workflow, release/archive/pin, actual
GitHub runtime and retention proofs remain separate.
